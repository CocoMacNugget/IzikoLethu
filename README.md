# IzikoLethu – Student Accommodation Platform

## 🏠 Overview
IzikoLethu is a web-based platform that helps students find safe and verified accommodation near their campus. Students can browse listings, view property details, save favourites, and apply directly to landlords in one place.

---

## 🎯 Purpose
The platform solves the problem of students struggling to find trusted and affordable accommodation by providing verified listings and direct communication with landlords.

---

## 🛠️ Technologies Used
- HTML, CSS, JavaScript
- PHP
- MySQL Database
